## 3. What is the most common mismatched field?

**SQL:**
```sql
SELECT field_name, COUNT(*) AS mismatch_count FROM v_fields WHERE verdict = 'mismatch' GROUP BY field_name ORDER BY mismatch_count DESC LIMIT 1
```

**Explanation:** Groups mismatched field results by field name and returns the field with the most mismatches.

**Result:**

| field_name | mismatch_count |
|---|---|
| incoterms | 8 |
